# 🎙️ Voice AI Assistant

A Voice AI Assistant built using **Python**, **Streamlit**, and **Google Gemini AI**. The application allows users to interact with AI through both voice and text. It converts speech to text, generates intelligent responses using Gemini AI, and converts the responses back into speech.

---

## 🚀 Features

- 🎤 Voice Input
- 💬 Text Chat
- 🤖 Gemini AI Integration
- 📝 Speech-to-Text
- 🔊 Text-to-Speech
- 💾 Chat History
- ⚙️ Interactive Sidebar
- 🧹 Clear Chat Option
- 🎨 Simple and Clean UI

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- gTTS (Google Text-to-Speech)
- HTML/CSS

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/NithinVaspula/Voice_AI_Assistant.git
```

Go to the project folder

```bash
cd Voice_AI_Assistant
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```text
GEMINI_API_KEY=YOUR_API_KEY
```

Run the application

```bash
streamlit run app.py
```
